# 010 — Research crawl rosters

**Type:** brainstorm
**Opened:** 2026-08-01
**Status:** open
**Thread:** follows 009
**Question:** which literature crawls would most change what we can see?

Ordered by expected value, not by topic. **Roster A is first because our own protocol says so** — the
cheapest way to be wrong fast is worth more than the cheapest way to feel confirmed.

Each roster states what it would *settle*, so a crawl that returns nothing is still informative.

## B. Substrates we have never looked at

**Function:** the claim is *cross-substrate*. We have checked exactly two substrates — human language
and neural-agent protocols. That is thin for a universality claim.

| Query | Why it expands the field |
|---|---|
| `bioelectric signaling pattern memory Levin morphogenetic code` | Non-neural, non-linguistic information system with genuine semantics. **Highest-value single item here** |
| `genetic code optimality error minimization alternative codes frozen accident` | A real code that evolved once — is it optimal or contingent? Directly parallel to our question |
| `molecular communication engineering information theory chemical signaling` | Substrate with no nervous system at all |
| `quorum sensing bacterial combinatorial signaling syntax` | Collective signaling without individual cognition |
| `swarm stigmergy indirect coordination information structure` | Meaning carried by environment modification rather than transmission |
| `cephalopod chromatophore signaling grammar structure` | Independent evolution of a visual, spatial, non-phonetic channel — **closest natural analogue to UWS** |
| `plant signaling networks information transfer mycorrhizal` | Maximum substrate distance from human language |
| `protein folding information geometry sequence structure map` | Structure determination as a semantic mapping problem |

**What it would settle:** whether convergent compositional structure shows up in substrates with no
neurons, no agents, and no training objective. That is the strongest possible form of the claim.

## Recommended order

1. **A** — falsification first. If the strongest legs break, we want to know this week.
2. **G** — the biggest known gap, and it carries the best evidence we have.
3. **C** — cheap, and it converts open questions into settled ones without new data.
4. **B** — the largest expansion of perception available; bioelectrics and cephalopod signaling first.
5. **D** — the dependency-order test lives here and is already priority 0.
6. **E**, **F**, **H** — as the corresponding work comes up.

**Discipline for every crawl:** preregister expectations before searching (S2), log whether
counter-evidence was easy or hard to find (S7), and record scope conditions on anything negative
before citing it (R2). Each roster becomes its own numbered note.
