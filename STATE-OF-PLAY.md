## 0. What "universal" means here — read this before anything else

`UNIVERSAL-IS-MATHEMATICAL-SCOPE` (DESIGN-CHOICE, owner ruling 2026-10-14):

> **Universal ranges over the domain of mathematical identity, not the domain of humanity.** A
> property is universal iff it is invariant across every region of reality in which the mathematics
> is the same. The object asserted to be shared is **the map of all possible symbolic geometry** —
> the classification of symbolic-geometric forms up to admissible transformation — not any notation,
> alphabet, or inventory drawn from it.

**The ruling resolved an inconsistency that was already in the registry.**
`UNIVERSALITY-IS-A-LEDGER` (priority 0) set the allowed prior as *"what any embodied computational
agent **in this universe** has"*; `UL-IS-TWO-TIER` (priority 1) warranted the natural tier on human
and primate core geometry, and its own scope line conceded the tested boundary *"currently sits
INSIDE primates."* Both entries were honest. Together they were not coherent. The program was
running two meanings of its central word at once, and the ledger had been built for the right one.

It is a **conditional** claim by construction — *wherever the mathematics is the same* — and it
shrinks with the domain of mathematical identity. That is deliberate and load-bearing.

## 1. What the ruling did to the program

**It made the ledger constitutive instead of instrumental** (`LEDGER-CLOSURE-IS-UNIVERSE-SCOPE`,
ARGUED, priority 0). An irreducible conventional residue *is* a free parameter the mathematics does
not fix and which could differ in another region; a closed ledger is exactly the condition that no
such parameter exists. **Closure and universe-scope invariance are the same statement**, not
evidence for one another. Three consequences:

- **The syntax layer already holds a partial universality result.** marks→map = **ℤ/2, proved and
  machine-checked**, is a *measured bound on how far syntax-layer universality falls short* — one
  bit, with a bootstrap route. The repo held it for months without knowing what it was.
- **The falsifier got cheap.** Exhibit one load-bearing element whose value the mathematics does not
  force. That is a **ledger audit, not an experiment** — the apparatus exists and it has never been
  run as a universality audit. This is now the program's best next move.
- **It explains why reading-invariance is the center** rather than one obligation among several: the
  reading procedure is the last place a local parameter can hide.

**It demoted the human evidence, and the trade is booked both ways**
(`HUMAN-UNIVERSALS-ARE-CORROBORATION`, ARGUED). *Gained:* the far-transfer record, the WEIRD-sampling
critiques, the Levinson critiques and the standing Changizi caveat `F1-c` are all objections to
inferring universality **from** human data — which the program no longer does, so none of them land
on the claim. **This repo has been absorbing damage from attacks on a position it does not need to
hold.** *Lost, and it is not small:* the human data was the only **empirical** support universality
had. The burden is now mathematical and nothing else. **Narrower and harder, better aimed.**

**What did not change:** `UL-IS-TWO-TIER` stands as *structure*, boundary still an empirical
variable, natural tier still the bootstrap surface. Only its warrant moved.
